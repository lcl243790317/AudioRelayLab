本轮实现：
- AudioAsset/AudioSource 统一 Bundle、导入、处理后录音、混合录音；沙盒音频库和 metadata。
- picker completion 取得 security scope，NSFileCoordinator 读取，UUID 命名、分块可取消复制、实际 PCM 解码。
- 可取消导入并切换内置测试音，UUID 拒绝迟到导入覆盖；选新音重置 preview、起点和实验状态。
- 起点进度、六项精调、独立 preview/5秒试听、七档倍速与 explicit apply。
- AVAudioPlayer 与 AVAudioEngine 共用起点/rate/volume；后者用 segment + TimePitch。
- Voice Lab：真实麦克风、Signalsmith pitch/formant、EQ/动态/去齿音/门/wet/gain，15 个预设。
- 实时监听、input/DSP output level、路由和延迟；耳机默认、扬声器可选、独立音量。
- 后台队列写 Float PCM CAF，处理后与混合录音回流主播放器、分享、删除。
- Mixer 音乐起点/rate/运行中 seek；原生 DynamicsProcessor 输出保护。
- 历史旧字段默认兼容；Voice 参数变化审计；日志和 CSV 增加源类型/格式/起点/rate。
- 前置会话/硬件格式验证、UUID/cancel、route/interruption/media/lifecycle 安全停止并手动重启。

音频选择问题的证据：
Git 原码的 controlsLocked=isImporting||machine.isActive 同时拦截外部与默认测试音；
旧导入没有取消/替换入口，provider 工作挂起时两条选择路径均被锁住。
旧导入也没有 NSFileCoordinator，scope 在 detached task 才申请；这些已修复。
自动测试验证立即取消导入→切 Bundle、旧任务不能覆盖、选音重置和真实编码文件导入。
没有本次失败的真机日志，不能确认某一个风险就是设备上唯一根因。
