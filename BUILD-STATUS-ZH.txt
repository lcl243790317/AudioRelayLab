本轮修改：
A/C/D/E 可新建；B 仅保留 legacy decode/history display，不可开始实验。
公开 CXCallObserver 只读可见通话状态前置检查，不识别具体 App、不获取号码。
会话激活成功后验证路由、输入可用性、有限采样率/声道，再创建播放器和 Engine 图。
本应用不使用 inputNode，不用 Swift catch 假装可以捕获 Objective-C assertion。
准备与开始分成两阶段；UUID token 状态机拒绝重复启动、取消后回调与过期任务。
中断最多自动恢复一次，失败即结束并清理；媒体服务和 Engine 配置改变不复用旧图。
App 音量保留 0...1，实际播放器音量回读；系统音量只读。
可选播放时长：AVAudioPlayer 真实裁剪 CAF，Engine 使用调度帧数限制，nil 为完整文件。
JSON schemaVersion=2；损坏单条隔离、缺失字段修复提示、未知值只用于历史。
真实 JSON 导入与 TXT/JSON/CSV 导出；自动日志含 UUID/sequence/uptime。
自动诊断不记录个人路由名、UID、私人路径；用户备注保留在用户控制的实验记录。

闪退根因证据边界：
没有 crash report / exception backtrace，不能宣称已定位唯一触发栈。
代码审查确认了激活前创建 Engine、缺少硬件格式前置验证、
准备阶段中断/取消和恢复失败清理不足等风险，本轮已修复这些风险路径。
Swift do/catch 只处理可抛出 Error，不能替代对 Objective-C 异常触发条件的前置防御。
